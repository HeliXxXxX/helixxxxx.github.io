# images/

Put your three photos here, named exactly:

- `01.jpg`
- `02.jpg`
- `03.jpg`

They can be any web format — if you use `.png` or `.webp`, change the matching
`src:` value in the `PHOTOS` array inside `index.html`.

Recommended: resize to about 1600px on the long edge and export at ~80% JPEG
quality. Anything bigger just makes the page slow.

Until a file exists, its slot shows a dashed "not found" box — the site still works.
